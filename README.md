# ivcs-radonc
## I Vibecoded a Contouring Station
### So you don't have to!
Simple radiotherapy contouring software for local use

# Quickstart
Download a release, unzip, run the Start script (For example: Start.cmd for Windows). A local server will start and the software should open in your default browser.

# Why?
I wanted something portable and easy to run. I think open, easy to distribute software is the best, most efficient way to use AI tools in general. Resources/energy/money are limited, so find an answer and share it! This is specially relevent for niche disciplines like Radiation Oncology

# Is this vibe coded?
Don't make me tap the sign (Yes)

# What's the intended use?
Mainly educational, as a learning tool for residents or for presentations. The scope is easy, local use, so expect a simple library menu for cases and Load/Save functions. No PACS server connection. This can read .Zip DICOM and exports RT Structs that could maybe be imported in your main, big TPS (This still requires testing). Always consult with Physics and your local protocols first.

# How can I help?
This is a little love project. It runs and performs well in my local machine (5000 series Ryzen Asus Zenbook running Windows 11 and a Ryzen Desktop running Fedora KDE), but everything is provided as is. MacOS builds are provided, but haven't had a chance to test. I will provide source as soon as I get around Github and clean things up a little, first time really using this. **Run it, test it, break it, but mainly, have fun with it and share the love!**
