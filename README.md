# ivcs-radonc
Simple radiotherapy contouring software for local use

# Why?
I wanted something portable and easy to run. I think open, easy to distribute software is the best, most efficient way to use AI tools in general. Resources/energy/money are limited, so find an answer and share it! This is specially relevent for niche disciplines like Radiation Oncology

# Is this vibe coded?
Don't make me tap the sign (Yes)

# What's the intended use?
Mainly educational, as a learning tool for residents or for presentations. The scope is easy, local use, so expect a simple library menu for cases and Load/Save functions. No PACS server connection. This can read .Zip DICOM and exports RT Structs that could maybe be imported in your main, big TPS. Always consult with Physics and your local protocols first.
