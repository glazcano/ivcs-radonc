# IVCS RT — 20260923

Cumulative changes since the previous public release, **20260915**.

This release expands acquisition support, substantially improves registration and fusion, enables multiplanar contouring, and adds 3D volume cleanup and detachable workspace panels. Processing and patient storage remain local, with manual saving.

## Image import and acquisition support

- **Integrated reconstruction of oblique and non-axial acquisitions**, including sagittal and coronal CT/MR stacks. Compatible axial images retain their direct import path.
- **Irregular parallel slice spacing** is handled using physical slice positions. Potential acquisition gaps are reported and excluded from valid image support rather than filled with invented anatomy.
- **Enhanced multiframe CT/MR support**, including shared/per-frame geometry, intensity scaling and supported compressed frames. Available volumes can be selected during import.
- Better separation of acquisitions using temporal position, echo, diffusion and other supported dimensional metadata, reducing accidental mixing of distinct volumes.
- **Improved intensity precision:** fractional values and values outside the signed 16-bit range are retained as Float32 when required. Basic Float Pixel Data and supported linear quantitative mappings retain their declared units.
- Corrected **MONOCHROME1 polarity** and intensity handling across axial, orthogonal and fusion views.
- Reconstruction preflight reports output dimensions and estimated memory requirements. Original DICOM files and native image geometry are preserved.

## Registration and fusion

- **Triplanar registration workspace** with axial, coronal and sagittal views, selectable as a horizontal row or an adjustable 1+2 layout.
- Direct mouse-driven **translation and rotation from any plane**, with synchronized updates across all three views.
- Restored reliable fusion previews, window/level handling, grayscale initialization, opacity, checkerboard, split-view and difference modes. Fixed the cyan-triangle and overexposed orange/white display problems.
- Dedicated **zoom, linked zoom and reset controls**. Zoom can be linked by relative magnification or physical image scale. Layout, divider and zoom-link preferences are retained.
- **Triplanar anatomical landmark selection**, registration undo/redo, comparison with the initial alignment and restoration of the selected transform.
- A configurable **volume of interest (VOI)** can prioritize anatomy during automatic registration. Intermediate automatic proposals are displayed in the three-plane preview.
- Improved local automatic registration with smoother mutual-information estimation, normalized correlation for suitable same-modality cases, and multiple coarse initializations before refinement.
- Corrected overlap evaluation for differently sized fields of view, reducing false “insufficient overlap” failures with small-field MR studies.
- Added initial/final metric comparisons, coverage and movement reporting to help review automatic proposals.
- **Preservation of existing relationships between linked series**, including native shared-frame relationships and saved registration groups. Conflict review identifies affected series and offers explicit relationship-priority or detachment choices.
- **External rigid DICOM REG import** as a reviewable proposal, with patient/reference and rigid-transform validation.

## Contouring and workspace

- **Contouring now works in the 1+2 and 2×2 layouts** across axial, coronal and sagittal image panes, including registered secondary and fusion displays.
- Plane edits are written to the reference volume. A complete stroke spanning multiple axial slices is a single undo action.
- Clear-slice operations now target the active editing plane. Polygon completion and navigation remain available within each pane.
- **Detachable tools/structures panel and main 1+2 pane** for multi-monitor workflows. Detached windows share the same session and return to the main workspace when closed.
- Fixed detached-window image fitting and temporary-tool keyboard handling.
- **Auto BODY now defaults to creating a new structure** instead of replacing an existing volume.
- Fixed active ROI selection after undoing structure creation, preventing invalid portable-session exports.

## 3D smoothing and cleanup

A new operation provides **3D median smoothing, morphological opening and closing, small-component removal, and enclosed-cavity filling**.

- Physical-radius parameters respect voxel spacing along each axis.
- Calculations run in a cancellable background worker.
- Preview highlights added and removed voxels and reports volume changes before acceptance.
- Output defaults to a new structure; locked structures cannot be overwritten.
- Accepted changes support undo. Invalid acquisition regions remain excluded.

The methods and references are documented in the application. These operations modify segmentation geometry and require review, particularly for thin structures.

## Temporal / 4D review

- Review compatible phases with phase selection, cine playback and comparison against the primary image.
- Generate **temporal MIP and AIP slice previews** without removing phase motion.
- Create an editable, undoable **ITV candidate** by combining a matching structure across compatible phases.
- Phase switching respects unsaved changes and preserves the nearest physical axial position.

MIP/AIP are review previews, not exported 3D dose-calculation datasets. ITV generation is a candidate union for review, not deformable contour propagation.

## Large studies, sessions and export

- Fixed **“Invalid string length”** when opening large imported studies or loading them for registration, using incremental transfers instead of duplicated, oversized JSON responses.
- Added the **streamed `.ivcs` portable-session format**, retaining supported legacy JSON import.
- Reduced transfer-related memory pressure through shared reference volumes, bounded image/mask records and incremental worker transfers.
- Improved large DICOM ZIP output with sequential writing, backpressure and write-error handling where streaming file access is available.
- Reconstructed-image exports preserve source references and include the derived image geometry required by their RTSTRUCT contours.
- Added memory/count budgets to contour history and bounded temporal-review caching.

Large studies still need sufficient RAM; these changes do not provide a fully disk-backed image-processing pipeline.

## Distribution and validation

- Portable packages are available for **Windows x64, macOS Apple Silicon/Intel, and Linux x64/ARM64**, alongside a source-code archive.
- Public packages use fresh synthetic staging, verified runtime archives, credential-pattern scans and SHA-256 checksums.
- The included **Luciano Bello CT/MR demonstration and contours are entirely synthetic**.
- Validation includes **103 automated tests**, TypeScript checking, production builds, Windows/Edge interaction tests, and native Windows portable startup/interface checks.
- macOS/Linux archives are provided, but native execution remains to be verified on those platforms.

## Current limits

Registration remains **rigid**, with no deformable registration, motion correction or dose accumulation. Automatic alignment still requires anatomical review. Nonparallel slice stacks, unsupported/ambiguous Enhanced dimensions, and some quantitative-map encodings remain unsupported. Reconstructed Float32 maps cannot yet be exported as derived DICOM images without a dedicated quantitative export path.

Destination-TPS acceptance testing remains pending; local DICOM and synthetic tests do not establish clinical validation.

## Updating

Save your work and stop the old application. Back up the entire `data` folder, extract the new portable package, and transfer that folder while both copies are stopped if you want to retain your cases. Install the complete package so the viewer and local server are updated together.
