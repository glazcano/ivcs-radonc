# IVCS RT — DICOM ZIP export (20260915)

Export RT > DICOM .zip includes the primary series original DICOM images and RTSTRUCT containing selected current contours. Unsaved contours are included. Existing contour preflight and filter-difference review apply.

Export RT > Advanced DICOM .zip additionally offers other series of the same patient with a rigid registration to the primary series. Current transforms take precedence over a saved library group. A loaded series with a shared Frame of Reference can use identity coordinates. Series without archived originals or a valid registration cannot be selected. Secondary-series contours are not included; RTSTRUCT belongs to the primary series.

All DICOM files share one DICOM folder, with short names independent of patient identifiers. Extract the ZIP and import that folder into the destination TPS. manifest.json records series identifiers, image counts and moving-to-reference matrices; README.txt describes import requirements.

## Registration representation

Images retain their original bytes, pixels, UIDs and geometry; there is no resampling or recompression. Each selected secondary series has a DICOM Spatial Registration Storage object (REG, 1.2.840.10008.5.1.4.1.1.66.1). It references both image sets and expresses the moving patient-LPS to reference patient-LPS rigid matrix, including the rotation pivot. Reference images have an identity matrix. Common Instance References include other studies when needed. Shared Frame of Reference registrations still identify the individual image sets explicitly.

The destination must support and apply DICOM REG. Merely importing the original images does not apply a manually adjusted transform. Compatibility with Elekta Monaco 6 or any other TPS has NOT been established by local tests; confirm the imported registration, image geometry and structures in the actual destination. No plan or dose is included. No assertion of image suitability for dose calculation is made; compressed/lossy source data remain compressed/lossy. Headerless original datasets remain unchanged and require destination support.

## Validation

Before packaging, verify patient, study, series, frame and SOP identifiers, dimensions, geometry and Pixel Data presence against the opened series. Include exactly the referenced SOP instances, reject conflicting duplicates and abort if an original is missing. Do not synthesize replacements. ZIP generation supports cancellation and does not save or modify the library.

Local tests check nonzero translation and rotation about a displaced pivot, cross-study references, shared-frame image references, original byte preservation, missing-image rejection, RTSTRUCT/REG references, cancellation and both UI downloads with unsaved registration edits. These tests do not replace import testing on a TPS.
